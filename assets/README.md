# Asset Pipeline

This folder is reserved for legal, original, or permissively licensed assets.

Use this structure:

```text
assets/
  models/
    stadium.glb
    batter.glb
    bowler.glb
  animations/
    batting-drive.fbx
    bowling-fast.fbx
    wicket-celebration.fbx
  audio/
    crowd-loop.ogg
    bat-hit.wav
    wicket.wav
  branding/
    logo.png
```

Allowed sources:

- original assets you create
- CC0 assets
- royalty-free assets with commercial use allowed
- paid assets with a valid license

Do not use ripped EA, Real Cricket, WCC, IPL, ICC, or copyrighted game assets.
